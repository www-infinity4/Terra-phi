# TerriPhi — Halloween Arcade

Repository: `www-infinity4/Terra-phi`. TerriPhi is the Halloween entertainment half of the Phi seasonal experiences. Its partner is PetriPhi (`www-infinity4/Petra-Phi`), the creative studio.

## First build

Open `index.html` in a modern browser. It includes a three-guess six-door pumpkin game, original Web Audio spooky effects, an interactive costume idea generator, a movie-source room, vintage historical sources and responsive Halloween styling.

External historical references: https://www.loc.gov/free-to-use/autumn-and-halloween/ ; https://publicdomainreview.org/collection/halloween-postcards/ . The classic film page is https://publicdomainreview.org/collection/night-of-the-living-dead . Verify rights of each *specific digital file* before embedding or distributing it. No film/music plays automatically.

## Reusable card integration

Use `WidgetPhi`'s `build_widget` with widget `seasonal-card` and modes `game`, `video`, `sound`, `costume`, or `vintage`. Mount its returned HTML in the host; load `browser/widgetphi-seasonal.js` once. Seasonal display is October-only by default. The hosting page controls placements, whether a pop-up is appropriate, and first-party preference routing. Users can dismiss a card for their session.

Use production URLs for art or video actions **only after the pages have been deployed**. Commit alone does not publish this site to QuantaPhi.org. Wallet star/share/collect buttons request actions; they never mint coins client-side.
